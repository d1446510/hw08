### 💻 程式用途與執行說明
* **程式用途**：本程式專為聚餐費用分攤設計。它能自動清理包含貨幣符號、千分位逗號與多餘空白的餐費資料，自動處理型別轉換，並依據「原始餐費計算服務費、扣除折價券、分攤人數」的邏輯計算出每人應付金額，最後自動比對個人預算，判斷是否超出額度。

  2. 依序或點擊上方「執行全部 (Run all)」按鈕執行各儲存格。
  3. 即可在各測試儲存格下方直接檢視輸出的費用明細與預算判定結果。

### ❓ 問題思考與回答

#### **問題一：為什麼 "4" 要先轉成數字，才能用於本題的分攤計算？**
* **回答**：
  在 Python 中，包裹在雙引號中的 `"4"` 的型別是**字串 (String)**，代表文字。而分攤計算所使用的除法運算子 `/` 僅能作用於**數值型別**（如整數 `int` 或浮點數 `float`）。
  如果直接拿字串 `"4"` 去做除法計算（例如 `total_payment / "4"`），Python 會因為不支援字串與數字間的除法而拋出 `TypeError` 錯誤。因此必須先使用 `int(people)` 將其轉換成整數 `4`，才能進行數學運算。

#### **問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？**
* **回答**：
  * **重新計算過程**：
    1. 扣除折價券後的剩餘餐費：$1,200 - 100 = 1,100$ 元。
    2. 依剩餘餐費計算服務費：$1,100 \times 0.10 = 110$ 元。
    3. 應付總額：$1,100 (剩餘餐費) + 110 (服務費) = 1,210$ 元。
  * **與規定結果不同的原因**：
    本題規定的服務費（$120$ 元）是**依據「原始餐費（1,200 元）」**計算的，因此應付總額為 $1,200 + 120 - 100 = 1,220$ 元。
    如果先扣掉折價券再算服務費，等於是把折價券的折扣也套用在服務費的計算基準上，導致店家實收的服務費縮水（從 120 元降為 110 元），所以總額會減少 10 元（變為 1,210 元）。這與一般餐飲業「服務費通常按原價成數計算」的商業習慣不符。
